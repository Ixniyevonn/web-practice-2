# Путевой журнал

Городской штаб в Санкт-Петербурге: светлая панель с погодой, делами, валютой, бюджетом, заметками и прогулкой по центру.

- **Сайт:** https://ixniyevonn.github.io/web-practice-2/
- **Репозиторий:** https://github.com/Ixniyevonn/web-practice-2
- **Тема:** панель города / жизнь в Петербурге
- **Стек:** SvelteKit 5, TypeScript, adapter-static, Leaflet, CSS
- **Нейросеть:** DeepSeek

## Что реализовано

По умолчанию на панели шесть виджетов: дела, погода, валюты, бюджет, прогулка и заметки. Часы и солнце можно добавить из галереи.

| Виджет | Что делает |
| --- | --- |
| **Дела** | Добавление, отметка и удаление задач; приоритеты, сроки, прогресс, drag & drop и сортировка с клавиатуры. |
| **Погода** | MET Norway: текущая температура, ветер, влажность, осадки и прогноз на 3 дня. |
| **Курс валют** | open.er-api.com: выбор базовой и котируемой валюты, конвертер суммы. RUB поддерживается. |
| **Время** | Часы в Санкт-Петербурге, Хельсинки, Таллине и Стокгольме. Добавляется из галереи. |
| **Солнце** | Восход, закат, длина дня и положение солнца на дуге. Добавляется из галереи. |
| **Бюджет** | Лимит 40 000 ₽, добавление и удаление расходов, остаток и прогресс. |
| **Прогулка по центру** | Интерактивная карта центра Петербурга на Leaflet: восемь реальных точек с адресами и описаниями. |
| **Заметки** | Три городские записи; добавление и удаление через диалог. |

### Управление

- Добавление виджета из галереи и запрет повторного добавления одного типа.
- Перетаскивание карточки за ручку слева: пустой слот показывает, куда встанет виджет, порядок сохраняется.
- Удаление одним нажатием, без подтверждения.
- Перемещение карточки выше/ниже из меню и стрелками с клавиатуры.
- Сброс к демонстрационному набору.
- Сетка в две колонки на компьютере и одна колонка на телефоне.

### Данные и отказы

- Погода, солнце и валюты запрашиваются напрямую из браузера.
- Каждый сетевой виджет независимо показывает загрузку, результат или ошибку с кнопкой «Повторить».
- Успешные ответы кэшируются в `localStorage`; при сбое сети показывается последний успешный ответ с временем обновления.
- Ошибка одной карточки не ломает остальные.
- Задачи, бюджет, заметки, настройки API и порядок виджетов сохраняются в `localStorage`.
- Изменения синхронизируются между вкладками через событие `storage`.
- Если `localStorage` недоступен, панель продолжает работать в памяти и сообщает об этом.

## API

### MET Norway

- Документация: https://api.met.no/weatherapi/locationforecast/2.0/documentation
- Погода: `https://api.met.no/weatherapi/locationforecast/2.0/compact?lat=59.9343&lon=30.3351`
- Солнце: `https://api.met.no/weatherapi/sunrise/3.0/sun?lat=59.9343&lon=30.3351&date=...&offset=+03:00`
- API-ключ не нужен.
- Open-Meteo не используется: из сети автора он не отвечает.

### open.er-api.com

- Документация: https://www.exchangerate-api.com/docs/free
- Запрос: `https://open.er-api.com/v6/latest/{base}`
- Поддерживает RUB, поэтому выбран вместо Frankfurter: в Frankfurter рубля нет.
- Курс обновляется источником примерно раз в сутки.
- API-ключ не нужен.

### Карта

Интерактивная карта центра Петербурга на Leaflet с тайлами Esri World Street Map: реальные улицы, реки, каналы и подписи. Восемь точек — Дворцовая площадь, Эрмитаж, Медный всадник, Исаакиевский собор, Стрелка Васильевского острова, Петропавловская крепость, Летний сад и Спас на Крови. У каждой точки есть адрес и описание. Карта не является навигатором.

## Архитектура

Задание просит HTML/CSS/обычный JS и классы. Автор попросил SvelteKit, поэтому UI сделан на Svelte 5, а требования лекций сохранены в архитектуре:

- `src/lib/state/widget.svelte.ts` — базовый класс `Widget` (адаптированный `UIComponent`): состояние, `serialize()`, `hydrate()`, `destroy()`, `requestSave()`.
- `src/lib/state/remote.svelte.ts` — общий класс для сетевых виджетов: `idle → loading → ready/error`, кэш, отмена запроса.
- `src/lib/state/widgets/*.svelte.ts` — классы `TodoWidget`, `WeatherWidget`, `CurrencyWidget`, `ClockWidget`, `SunWidget`, `BudgetWidget`, `MapWidget`, `NotesWidget`.
- `src/lib/state/widgets/factory.ts` — фабрика виджетов.
- `src/lib/state/dashboard.svelte.ts` — класс `Dashboard`: коллекция, `addWidget()`, `removeWidget()`, `moveTo()`, сохранение, загрузка и синхронизация вкладок.
- `src/lib/components/` — Svelte-компоненты только отображают состояние классов.
- `src/lib/api/` — модули MET Norway и open.er-api.com с проверкой ответа.
- `src/lib/core/` — безопасный `localStorage`, HTTP-обёртка, форматирование дат и чисел.
- `src/lib/content.ts` — контент: город, виджеты, демо-задачи, заметки, расходы, точки прогулки.

Схема сохранения:

```json
{
  "version": 1,
  "savedAt": 1761740000000,
  "widgets": [
    {
      "type": "todo",
      "collapsed": false,
      "data": { "tasks": [], "filter": "all" }
    }
  ]
}
```

Ключ: `pj-dashboard-v4`. Кэши API: `pj-cache-weather-v2`, `pj-cache-sun-v2`, `pj-cache-currency-{BASE}`.

## Публикация на GitHub Pages

В репозитории есть workflow `.github/workflows/deploy.yml`: пуш в `main` собирает сайт и публикует `build/` через GitHub Pages.

1. Включите **Settings → Pages → Source: GitHub Actions**.
2. Сделайте пуш в `main` или запустите workflow вручную.
3. Сайт будет доступен по адресу `https://ixniyevonn.github.io/web-practice-2/`.

Ручной вариант:

1. Соберите сайт: `npm run build:pages`.
2. Опубликуйте содержимое `build/` в ветку `gh-pages`.
3. В настройках репозитория: **Settings → Pages → Deploy from a branch → gh-pages / root**.

Если репозиторий называется иначе, измените `BASE_PATH` в скрипте `build:pages`, путь в workflow и `site.siteUrl` в `src/lib/content.ts`.

## Проверка

- Добавить все виджеты, перетащить каждый за ручку и удалить без подтверждения.
- Пять раз удалить и добавить виджет — действие должно выполняться один раз.
- Добавить, отметить и удалить задачу; перетащить её за ручку; обновить страницу.
- Проверить погоду и валюты при включённой сети.
- Отключить сеть: должны появиться ошибки и кнопки «Повторить», а не вымышленные данные.
- Переключить базовую валюту, поменять валюты местами, изменить сумму.
- Выбрать точку в списке и увидеть её описание.
- Добавить заметку и расход, обновить страницу.
- Открыть сайт в двух вкладках и добавить задачу в одной — вторая должна обновиться.
- Проверить 390, 768 и 1440 px; клавиатурный фокус и `prefers-reduced-motion`.

## Честность и ограничения

- Задачи, заметки и расходы — демонстрационные данные.
- Погода и валюты — реальные ответы API.
- Карта показывает восемь точек и не строит маршрут: это не навигатор, адреса указаны в списке.
- Сайт создан с помощью DeepSeek; промпты и решения описаны выше.
